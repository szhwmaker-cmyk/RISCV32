# RV32E SoC Register Map
# 寄存器映射文档

## Memory Map Overview

| 地址范围 | 大小 | 设备 | 描述 |
|---------|------|------|------|
| 0x00000000 - 0x00003FFF | 16KB | Boot ROM | 启动程序存储 |
| 0x20000000 - 0x2000FFFF | 64KB | RAM | 主内存 |
| 0x40000000 - 0x40000FFF | 4KB | UART | 串口通信 |
| 0x40001000 - 0x40001FFF | 4KB | GPIO | 通用I/O |
| 0x40002000 - 0x40002FFF | 4KB | Timer | 定时器 |
| 0x40003000 - 0x40003FFF | 4KB | SPI Master | SPI主控制器 |
| 0x40004000 - 0x40004FFF | 4KB | I2C Master | I2C主控制器 |

## UART Registers

**基地址**: 0x40000000

### 0x00: DATA
**数据寄存器**

| 位 | 名称 | 访问 | 描述 |
|----|------|------|------|
| 7:0 | DATA | R/W | 发送/接收数据 |
| 31:8 | - | - | 保留 |

- 写入：发送一个字节到TX FIFO
- 读取：从RX FIFO读取一个字节

### 0x04: STATUS
**状态寄存器**

| 位 | 名称 | 访问 | 描述 |
|----|------|------|------|
| 0 | TX_READY | R | TX FIFO有空间 (1=有空间) |
| 1 | RX_VALID | R | RX FIFO有数据 (1=有数据) |
| 2 | TX_EMPTY | R | TX FIFO为空 (1=空) |
| 3 | RX_FULL | R | RX FIFO已满 (1=满) |
| 31:4 | - | - | 保留 |

### 0x08: CTRL
**控制寄存器**

| 位 | 名称 | 访问 | 描述 |
|----|------|------|------|
| 0 | TX_EN | R/W | 发送使能 |
| 1 | RX_EN | R/W | 接收使能 |
| 2 | TX_IRQ_EN | R/W | 发送中断使能 |
| 3 | RX_IRQ_EN | R/W | 接收中断使能 |
| 31:4 | - | - | 保留 |

### 0x0C: DIV
**波特率分频器**

| 位 | 名称 | 访问 | 描述 |
|----|------|------|------|
| 31:0 | DIVISOR | R/W | 时钟分频值 |

波特率计算: `Baudrate = ClockFreq / DIVISOR`

示例：50MHz时钟，115200波特率: `DIVISOR = 50000000 / 115200 = 434`

## GPIO Registers

**基地址**: 0x40001000

### 0x00: DATA_IN
**输入数据寄存器**

| 位 | 名称 | 访问 | 描述 |
|----|------|------|------|
| 15:0 | DATA_IN | R | GPIO输入值 |
| 31:16 | - | - | 保留 |

### 0x04: DATA_OUT
**输出数据寄存器**

| 位 | 名称 | 访问 | 描述 |
|----|------|------|------|
| 15:0 | DATA_OUT | R/W | GPIO输出值 |
| 31:16 | - | - | 保留 |

### 0x08: DIR
**方向寄存器**

| 位 | 名称 | 访问 | 描述 |
|----|------|------|------|
| 15:0 | DIRECTION | R/W | 方向控制 (0=输入, 1=输出) |
| 31:16 | - | - | 保留 |

### 0x0C: IRQ_EN
**中断使能寄存器**

| 位 | 名称 | 访问 | 描述 |
|----|------|------|------|
| 15:0 | IRQ_EN | R/W | 每位对应一个GPIO引脚的中断使能 |
| 31:16 | - | - | 保留 |

### 0x10: IRQ_MODE
**中断模式寄存器**

| 位 | 名称 | 访问 | 描述 |
|----|------|------|------|
| 1:0 | PIN0_MODE | R/W | 引脚0中断模式 |
| 3:2 | PIN1_MODE | R/W | 引脚1中断模式 |
| ... | ... | ... | ... |
| 31:30 | PIN15_MODE | R/W | 引脚15中断模式 |

中断模式值:
- 00: 上升沿触发
- 01: 下降沿触发
- 10: 双沿触发

### 0x14: IRQ_STAT
**中断状态寄存器**

| 位 | 名称 | 访问 | 描述 |
|----|------|------|------|
| 15:0 | IRQ_STATUS | R/W1C | 中断状态位（写1清除） |
| 31:16 | - | - | 保留 |

## Timer Registers

**基地址**: 0x40002000

### 0x00: CTRL
**控制寄存器**

| 位 | 名称 | 访问 | 描述 |
|----|------|------|------|
| 0 | ENABLE | R/W | 定时器使能 |
| 1 | IRQ_EN | R/W | 中断使能 |
| 2 | AUTO_RELOAD | R/W | 自动重载模式 |
| 3 | ONE_SHOT | R/W | 单次模式 |
| 31:4 | - | - | 保留 |

### 0x04: STATUS
**状态寄存器**

| 位 | 名称 | 访问 | 描述 |
|----|------|------|------|
| 0 | IRQ_FLAG | R/W1C | 中断标志（写1清除） |
| 31:1 | - | - | 保留 |

### 0x08: LOAD
**重载值寄存器**

| 位 | 名称 | 访问 | 描述 |
|----|------|------|------|
| 31:0 | LOAD_VALUE | R/W | 定时器重载值 |

### 0x0C: COUNT
**计数值寄存器**

| 位 | 名称 | 访问 | 描述 |
|----|------|------|------|
| 31:0 | COUNT_VALUE | R | 当前计数值 |

### 0x10: PRESCAL
**预分频器**

| 位 | 名称 | 访问 | 描述 |
|----|------|------|------|
| 31:0 | PRESCALER | R/W | 预分频值 |

定时器时钟 = 系统时钟 / (PRESCALER + 1)

### 0x08: DATA
**数据寄存器**

| 位 | 名称 | 访问 | 描述 |
|----|------|------|------|

## I2C Master Registers

**基地址**: 0x40004000

### 0x00: CTRL
**控制寄存器**

| 位 | 名称 | 访问 | 描述 |
|----|------|------|------|
| 0 | START | R/W | 生成START条件 |
| 1 | STOP | R/W | 生成STOP条件 |
| 2 | READ | R/W | 读操作 |
| 3 | WRITE | R/W | 写操作 |
| 4 | ACK | R/W | ACK/NACK值 (0=ACK, 1=NACK) |
| 5 | IRQ_EN | R/W | 中断使能 |
| 31:6 | - | - | 保留 |

### 0x04: STATUS
**状态寄存器**

| 位 | 名称 | 访问 | 描述 |
|----|------|------|------|
| 0 | BUSY | R | 传输进行中 |
| 1 | DONE | R | 传输完成 |
| 2 | ACK_RECV | R | 接收到ACK |
| 3 | ARB_LOST | R | 仲裁丢失 |
| 31:4 | - | - | 保留 |

### 0x08: ADDR
**地址寄存器**

| 位 | 名称 | 访问 | 描述 |
|----|------|------|------|
| 7:0 | ADDRESS | R/W | I2C地址（7位地址 + R/W位） |
| 31:8 | - | - | 保留 |

### 0x0C: DATA
**数据寄存器**

| 位 | 名称 | 访问 | 描述 |
|----|------|------|------|
| 7:0 | DATA | R/W | 发送/接收数据 |
| 31:8 | - | - | 保留 |

### 0x10: DIV
**时钟分频器**

| 位 | 名称 | 访问 | 描述 |
|----|------|------|------|
| 15:0 | DIVISOR | R/W | I2C时钟分频值 |
| 31:16 | - | - | 保留 |

I2C时钟计算: `SCL_freq = ClockFreq / (4 * DIVISOR)`

示例：
- 标准模式(100kHz): DIVISOR = 50000000 / (4 * 100000) = 125
- 快速模式(400kHz): DIVISOR = 50000000 / (4 * 400000) = 31

## 编程示例

### UART发送字符串

```c
void uart_puts(const char *s) {
    while (*s) {
        // 等待TX就绪
        while (!(UART_STATUS & 0x01));
        // 发送字符
        UART_DATA = *s++;
    }
}
```

### GPIO LED闪烁

```c
void led_blink(void) {
    // 设置为输出
    GPIO_DIR = 0xFFFF;

    while (1) {
        GPIO_OUT = 0xAAAA;
        delay(1000);
        GPIO_OUT = 0x5555;
        delay(1000);
    }
}
```

### Timer延时

```c
void timer_delay_ms(uint32_t ms) {
    // 配置定时器：50MHz时钟，1ms延时
    TIMER_PRESCAL = 49999;  // 1kHz tick
    TIMER_LOAD = ms;
    TIMER_CTRL = 0x09;  // 使能 + 单次模式

    // 等待完成
    while (!(TIMER_STATUS & 0x01));

    // 清除标志
    TIMER_STATUS = 0x01;
}
```
