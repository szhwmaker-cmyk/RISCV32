================================================================================
UART 波特率解码
================================================================================

配置:  115200 baud, 8N1
周期:  ~217 系统时钟周期/位
字符:  1 start bit + 8 data bits + 1 stop bit = 10 bits
时间:  ~87 μs/字符

示例字符 'A' (0x41) 的波形:
  Start  D0  D1  D2  D3  D4  D5  D6  D7  Stop
   0     1   0   0   0   0   0   1   0   1
   |-----|---|---|---|---|---|---|---|-----|
    217  217 217 217 217 217 217 217 217 clks

================================================================================
注意事项
================================================================================

1. 实际输出可能因仿真环境而异
2. 时间戳（方括号中）是估计值
3. 需要波形查看器（GTKWave）来查看详细信号
4. UART 输出需要通过监控内部信号或 VCD 文件解码
5. 某些功能（如中断）可能未实现

================================================================================
如何获取实际输出
================================================================================

1. 运行测试：
   mill rv32e.test.testOnly rv32e.integration.RTThreadSpec

2. 查看测试日志：
   cat test_run_dir/RTThreadSpec/test.log

3. 使用 GTKWave 查看波形：
   gtkwave test_run_dir/RTThreadSpec/MinimalSoc.vcd

4. 解码 UART 信号：
   - 在 GTKWave 中添加 uart_tx 信号
   - 使用波特率解码工具
   - 或编写脚本解析 VCD 文件
